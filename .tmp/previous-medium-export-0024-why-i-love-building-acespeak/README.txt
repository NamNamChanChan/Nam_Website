HOW TO POST THIS TO MEDIUM
==========================

1. Open  why-i-love-building-acespeak.html  in Chrome.
2. Press Cmd+A, then Cmd+C.
3. In Medium, start a NEW story and press Cmd+V.
   Headings, bold, links, code blocks and quotes come through.
4. Each image shows as a preview with a ready-to-use caption: "Photo 1 - …",
   "Photo 2 - …", and so on. For each one, DRAG the matching numbered file below
   from this folder in ABOVE its caption — the "Photo N - …" line stays as the
   caption, no editing needed.

5. Before publishing, add these five suggested Medium topics:
   1. Artificial Intelligence
   2. Public Speaking
   3. Startups
   4. Leadership
   5. Product Development

Photos in this folder (in order):
  1-why-i-love-building-acespeak-banner.png   →   Photo 1 - Speaking stays human.
  2-why-i-love-building-acespeak-speaking-stays-human.png   →   Photo 2 - AI can help with the words. Presence, expression and meaning still belong to the speaker.
  3-why-i-love-building-acespeak-joy-of-speaking.png   →   Photo 3 - The ambition is not simply better performance. It is a healthier and more enjoyable relationship with speaking.

Tip: once the post is live on nam-ai.uk, the very easiest route is
Medium → "Import a story" → paste the post URL (it pulls text + images).
